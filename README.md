# زعيم الوحوش — Android starter project

هذا مشروع بداية لتطبيق Android باسم **زعيم الوحوش**. النسخة الحالية تفتح موقع TikTok الرسمي داخل التطبيق، مع إعدادات WebView أساسية لتقليل الحمل وتحسين الاستجابة.

## مهم قبل النشر
- هذا ليس تطبيق TikTok رسميًا، ولا توجد واجهة API عامة تتيح استنساخ صفحة For You بالكامل أو الوصول غير المقيّد إلى كل فيديوهات TikTok.
- المشروع لا يسحب الفيديوهات أو يتجاوز قيود TikTok؛ يعرض الموقع الرسمي فقط. قد يقيّد TikTok تسجيل الدخول أو التشغيل داخل WebView، وقد تحتاج إلى فتح الروابط في المتصفح.
- لا يمكن ضمان أنه أسرع من TikTok Lite على كل شبكة. السرعة تعتمد على تغطية الشبكة، ضغط الفيديو، وسياسات TikTok. هذا المشروع يوفّر نقطة بداية خفيفة، وليس محرك بث جديدًا.
- لا تستخدم شعار TikTok أو علامته بطريقة توحي بأن التطبيق رسمي أو تابع لـ TikTok.

## إنشاء APK من GitHub
1. أنشئ مستودعًا جديدًا على GitHub.
2. فك ضغط ملف ZIP وارفع **محتويات** المجلد إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** وفعّل GitHub Actions إذا طلب ذلك.
4. ادخل إلى سير العمل **Build Android APK** وشغّل **Run workflow**، أو ادفع commit جديدًا.
5. بعد اكتمال البناء، افتح نتيجة التشغيل ثم قسم **Artifacts** ونزّل `zaeem-alwohoosh-debug-apk`.
6. فك ضغط الـ artifact وثبّت ملف APK على هاتف Android. قد تحتاج إلى السماح بالتثبيت من هذا المصدر.

## بناء محلي
يتطلب JDK 17 وAndroid SDK وGradle:
```bash
gradle assembleDebug
```
ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## ما الذي يحتويه المشروع؟
- تطبيق Android بسيط باسم زعيم الوحوش.
- WebView يفتح `https://www.tiktok.com/`.
- تمرير عمودي، JavaScript وDOM storage مفعّلان لتوافق الموقع.
- تخزين WebView المؤقت مفعّل.
- GitHub Actions لبناء APK تلقائيًا.
